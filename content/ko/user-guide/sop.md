# S&OP

*팀별 판매·생산계획을 조율하여 전사 마스터 플랜을 효율적으로 확정합니다*

## [1] S&OP 활용 가이드

수요예측 결과를 현장에서 활용하기 위해서는 예측 이후의 판매·생산 계획을 어떻게 수립하고 조율하는지가 중요합니다. 현업에서는 같은 예측값을 보더라도 부서와 역할에 따라 서로 다른 판단이 이루어지며, 이 과정에서 동시에 여러 계획이 사내에 존재하게 됩니다.

딥플로우의 S&OP 기능은 이러한 부서별 판단과 조정 과정을 하나의 흐름으로 연결합니다. 판매 계획과 생산 계획을 전사 관점에서 종합하고, 최종 실행 가능한 단일 계획으로 확정할 수 있도록 돕습니다. 각 사용자의 기록과 결재 정보가 시스템에 기록되어, 계획 수립 과정의 맥락과 의사결정 이력을 함께 관리할 수 있습니다.

수요예측을 기준으로 팀별 판매·생산 계획을 조율하여 마스터 플랜을 효율적으로 확정해 보세요.

## [2] 판매계획 작성 및 관리

![판매계획 화면](/images/sop/01.png)

판매계획 탭은 딥플로우 수요예측 결과를 참고하여 실무자가 판매계획을 조정·확정할 때 사용하는 화면입니다. 프로모션 계획, 유통 채널 이슈, 내부 전략 등으로 예측값과 실무자의 판단이 다른 경우, 해당 품목의 목표 판매량을 수정하고 그 근거를 함께 기록합니다.

작성된 판매계획은 팀 단위로 관리되며, 월계획 확정 여부를 통해 해당 팀의 판매계획 수립 완료 여부를 유관 부서에 알릴 수 있습니다.

### [2.1] 판매계획 입력 및 수정

![판매계획 입력 화면](/images/sop/02.png)

영업1팀 등 자신의 팀 판매계획을 딥플로우에 바로 입력합니다.

- **[목표 판매량 수정]** 버튼을 클릭하면 표 편집 모드가 시작되고, 편집 가능한 열이 파란색 강조 색상으로 전환됩니다.

> **주의:** 저장 충돌 및 데이터 유실 방지를 위해 **시트당 1명만 편집**할 수 있도록 제한되어 있습니다. (여러 사용자 동시 편집 미지원)
>
> 편집 중인 사용자가 [저장] 또는 [수정 취소]를 완료해야 다른 사용자가 해당 시트를 편집할 수 있습니다.

아래 정보와 그래프를 과거 자료로서 참고하고, 예정된 프로모션 또는 단종 계획 등 이벤트를 고려하여 목표 판매량과 조정 사유를 저장합니다.

- 1개 품목에 대해 체크박스를 선택하면 그래프가 하단 영역에 나타납니다.
- 표에 기입한 목표 판매량이 그래프에 **노란색 선**으로 표시되며, **녹색 선(판매량(최종))** 은 대시보드 탭에서 기입된 최종 판매 계획을 의미합니다.

### [2.2] 판매계획 엑셀 업로드

![판매계획 엑셀 업로드](/images/sop/03.png)

**[판매계획 업로드]** 를 통해 여러 품목의 목표 판매량과 조정 사유를 일괄로 편리하게 입력할 수 있습니다.

- 제공되는 양식에는 해당 월의 수요예측 대상 품목이 리스트업되어 있습니다.
- 판매계획을 수립하고자 하는 품목에 대해 목표 판매량과 조정 사유를 입력하고, 해당되지 않는 품목은 삭제합니다.

> **주의:** **필수 입력**: 품번, 목표 판매량, 조정 사유
>
> 공란 셀이 없도록 유의해 주시기 바랍니다.

### [2.3] 팀별 시트 관리

![팀별 시트 관리](/images/sop/04.png)

판매계획 수립에 여러 팀이 관여하는 경우 팀별 시트 관리가 적합합니다. 매니저 권한을 가진 사용자는 팀 시트의 생성·수정·삭제가 가능합니다.

- **[+] 버튼 클릭**: ‘부서명’으로 가장 우측에 새 시트 생성
- **시트에서 우클릭**: 시트명 변경 또는 삭제

### [2.4] 판매계획 결재

![판매계획 결재](/images/sop/05.png)

관리자는 팀 시트에서 실무자의 판매계획을 품목 단위로 승인 또는 반려할 수 있습니다.

1. **품목 선택**: 품목들을 체크박스로 선택하고 **[선택 승인/반려]** 를 클릭합니다.
2. **승인 또는 반려**: **[승인]** 또는 **[반려]** 를 클릭합니다.
3. **결재 완료 확인**: 결재 완료 시 표에 최종결재자 이름과 결재 일시가 표시됩니다.

> **팁:** **빠른 승인 Tip**: [전체 상태] 필터에서 ‘검토대기’ 또는 ‘AI예측’ 상태인 품목만 필터링 → 표 헤더의 체크박스 클릭하여 품목 전체 선택 → 승인 처리

‘검토대기’ 또는 ‘AI 예측’ 상태인 품목에 대해 결재가 가능합니다.

- **AI 예측 상태**: 딥플로우에서 수요예측이 완료된 상태. 별도 조정 없이 판매계획으로 승인 가능합니다.
- **검토대기 상태**: 사용자가 AI 예측을 참고하여 목표 판매량과 조정 사유를 기입한 상태입니다.

### [2.5] 월계획 확정

![월계획 확정](/images/sop/06.png)

시트의 모든 품목을 검토하여 승인 상태로 결재를 마쳤다면 **[판매 계획 확정]** 을 진행합니다.

- [판매 계획 확정]을 통해 해당 팀의 계획 수립이 완료되었음을 표현할 수 있습니다.
- S&OP 메뉴 > 대시보드 탭에서 팀별 판매·생산계획 수량과 확정 여부가 표시됩니다.

### [2.6] 조정이력 확인

![조정이력 확인](/images/sop/07.png)

**[조정 내역 보기]** 를 클릭하여 목표 판매량 조정 활동과 결재 이력을 확인합니다.

## [3] 생산계획 작성 및 관리

![생산계획 화면](/images/sop/08.png)

생산계획 또한 판매계획과 동일한 방법으로 진행됩니다.

`작성 또는 업로드` → `결재(승인·반려)` → `월계획 확정`

순서로 진행되며, 조정내역 보기 및 팀별 시트 관리 기능도 동일하게 제공됩니다. 자세한 사용 방법은 **[2] 판매계획 작성 및 관리**의 [2.1]~[2.6]을 참고해 주세요.

> **팁:** **생산계획 입력 및 수정**
>
> - **딥플로우에서 바로 입력**: [적정 생산량 수정] 버튼 클릭 → ‘적정 생산량(사용자 확정)’과 ‘조정 사유’ 셀에 생산 수량 및 근거 기입 → [저장] 버튼 클릭
> - **엑셀 업로드**: [업로드] 버튼 클릭 → 템플릿 다운로드 → 생산 수량 및 근거 기입 → [판매계획 업로드] 클릭 → 작업한 파일 선택
>
> ※ 저장 충돌 및 데이터 유실 방지를 위해 시트당 1명만 편집할 수 있도록 제한되어 있습니다.

## [4] S&OP 계획 확정 (대시보드)

![S&OP 대시보드](/images/sop/09.png)

대시보드에서는 각 팀에서 수립한 판매·생산계획을 토대로 최종 S&OP 계획을 확정합니다. 강조 색상으로 표시되는 **판매량(최종)**, **생산량(최종)** 이 대시보드에서 기입할 셀입니다.

해당 월의 판매·생산계획 수립 후 대시보드 화면에 진입하면, 각 팀에서 입력한 수량이 조회되며 ‘판매량(최종)’과 ‘생산량(최종)’은 공란으로 표시됩니다. 두 셀에 값을 입력하면 최종 계획이 하단 그래프에 표현됩니다.

![판매·생산 자동 채우기](/images/sop/10.png)

**[판매·생산 자동 채우기]** 기능을 사용하면 ‘판매량(최종)’, ‘생산량(최종)’ 셀을 편리하게 채울 수 있습니다. 이는 각 팀의 판매·생산계획 또는 AI 수요예측 중 하나의 값을 인용하여 셀을 자동으로 채우는 기능입니다.

> **팁:** ‘판매계획’ 탭의 그래프에서도 최종 계획이 표현되므로, 실무자는 팀에서 수립한 판매계획 대비 최종 계획이 어떤 모습으로 확정되었는지 파악할 수 있습니다.
