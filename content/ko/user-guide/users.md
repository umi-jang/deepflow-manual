# 사용자 관리

*개인 설정을 변경하고 서비스 사용자를 초대·관리합니다*

개인 설정을 변경하고 서비스 사용자를 추가할 수 있습니다.

## [1] 프로필 확인 및 수정

![프로필 화면](/images/users/01.png)

1. **기본 정보 확인**: 이메일 인증 시 초기 입력한 정보를 확인합니다.
2. **최근 로그인 정보 확인**: 최근 로그인 일시와 위치 등을 확인합니다.
3. **정보 수정**: **[수정]** 버튼을 클릭하여 입력된 정보를 수정합니다. **이름 / 부서 / 언어**를 수정할 수 있으며, 언어는 한국어와 영어 중 선택할 수 있습니다.

## [2] 비밀번호 변경

![비밀번호 변경](/images/users/02.png)

1. **기존 비밀번호 인증**: 기존 사용하던 비밀번호를 입력하여 인증합니다.
2. **새 비밀번호 저장**: 새로운 비밀번호를 입력하고 **[저장]** 버튼을 누르면, 비밀번호 변경이 완료됩니다.

## [3] 사용자 관리

![사용자 관리](/images/users/03.png)

1. **사용자 목록 조회**: 현재 등록된 사용자 목록을 조회합니다.
2. **사용자 관리**: 더보기 버튼을 클릭하여 등록된 사용자를 관리할 수 있습니다. 기존에 등록되어 있는 사용자를 삭제할 수 있습니다.
3. **사용자 초대**: **[초대]** 버튼을 클릭하여 새로운 사용자를 초대합니다.
   - 초대할 이메일, 이름, 부서를 입력합니다.
   - 초대한 사용자가 사용할 application을 선택합니다. (여러 서비스 중복 선택 가능)
   - **[초대]** 버튼을 누르면 입력한 이메일을 통해 초대 링크가 발송되며, 이메일 인증 이후 서비스를 이용할 수 있습니다.

![사용자 초대](/images/users/04.png)
