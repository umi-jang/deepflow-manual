# 릴리즈 노트

## 2026 — 05 — 26 · v3.0

**New** · **Improvement**

### 신규 사용자 가이드 사이트 공개

Mintlify 기반의 docs 사이트로 사용자 가이드를 전면 개편했습니다.

**새로운 기능**

- 한국어 / 영어 이중 언어 지원
- 메뉴별 가이드 7종 정리 (수요예측, 재고관리, BI, MI, 데이터셋, S&OP, 사용자 관리)
- 릴리즈 노트 타임라인 도입

**개선사항**

- 페이지 컨텍스트 메뉴(ChatGPT / Claude / Cursor 등으로 바로 보내기) 추가
- 시각적 디자인 통일 (Mintlify almond 테마 + 브랜드 컬러)

**관련 매뉴얼:** [수요예측](/ko/forecast) · [재고관리](/ko/inventory) · [S&OP](/ko/sop)

## 2026 — 04 — 15 · v2.9

**Improvement** · **Fix**

### 수요예측 정확도 개선 및 안정성 강화

예측 모델의 정확도를 평균 6.2% 향상시키고, 대량 데이터 처리 시 발생하던 일부 오류를 수정했습니다.

**개선사항**

- 계절성 패턴 인식 알고리즘 고도화 (월별 / 주별 패턴 동시 학습)
- 이상치 자동 탐지 임계값 조정으로 예측 안정성 향상
- 대량 SKU 학습 시 처리 속도 약 30% 개선

**수정사항**

- 특정 조건에서 학습 작업이 중단되던 이슈 수정
- 한글 SKU명 표시 시 깨짐 현상 수정

**관련 매뉴얼:** [수요예측](/ko/forecast) · [데이터셋](/ko/dataset)

## 2026 — 03 — 03 · v2.8

**New**

### 재고 시뮬레이션 기능 추가

예측 결과를 기반으로 재고 시나리오를 시뮬레이션할 수 있는 새로운 기능을 추가했습니다.

**새로운 기능**

- 안전재고, 발주주기, 리드타임을 직접 조정하며 시나리오 비교
- 품절 위험 / 과잉 재고 비율을 실시간으로 시각화
- 시뮬레이션 결과를 Excel로 내보내기

**관련 매뉴얼:** [재고관리](/ko/inventory) · [S&OP](/ko/sop)
