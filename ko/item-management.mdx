---

품목의 속성 정보를 수정하고, 사용자 속성과 담당자를 관리하며, 단종·활성 여부를 설정하고, 순차 판매되는 품목을 예측 그룹으로 묶을 수 있습니다. 이 문서는 실제 사용 시나리오 단위로 각 기능의 사용법을 안내합니다.

<Frame>
  <img src="/images/item-management/01-overview.png" alt="품목관리 화면" />
</Frame>

## 주요 용어

- **활성 / 비활성** : 수요예측 화면에 이 품목을 노출할지 결정합니다. **활성 품목이라면 예측값이 없더라도 수요예측 화면에 품목이 표시됩니다.** 비활성 품목은 예측값이 있어도 화면에 표시되지 않습니다.
- **단종 / 단종 예정** : 특정 시점부터 판매가 종료됨을 표시합니다. **활성 여부와 단종 상태는 서로 영향을 주지 않습니다.** 지정한 단종일이 지나더라도 활성 상태가 유지되며, 활성 상태인 단종 품목은 수요예측에 노출됩니다.
- **예측 그룹** : 제품 리뉴얼·업그레이드 등의 사유로 과거 판매 흐름을 이어서 볼 필요가 있는 유사 품목을 그룹으로 구성합니다. 대표 품목만 수요예측 메뉴에 노출되고, 다른 그룹 구성 품목들의 출고량이 대표 품목으로 합산됩니다.
- **신제품** : 출시일이 신제품 판정 기준 개월수 이내인 품목입니다. 품명 옆에 '신제품' 태그가 자동으로 붙습니다.

## [1] 품목 검색하고 상세 정보 확인하기

원하는 품목을 검색·필터로 찾고, 행을 클릭해 상세 정보를 확인합니다.

<Frame>
  <img src="/images/item-management/02-search.png" alt="품목 검색 화면" />
</Frame>

<Steps>
  <Step title="품번·품명으로 검색">
    검색창에 품번 또는 품명 일부를 입력하면 검색어를 포함하는 품목이 목록에 표시됩니다.
  </Step>
  <Step title="필터로 좁히기">
    카테고리 필터(대·중·소 카테고리)와 활성 여부·단종 여부·신제품 여부 드롭다운으로 조건을 좁힙니다. 각 드롭다운은 옵션 1개만 선택되며, 검색어와 선택한 필터 조건이 모두 함께 적용되어 결과가 좁혀집니다.
  </Step>
  <Step title="정렬하기">
    컬럼 헤더를 클릭하면 그 컬럼 기준으로 정렬되고, 같은 헤더를 다시 클릭하면 오름차순↔내림차순이 전환됩니다.
  </Step>
  <Step title="상세 패널 열기">
    품목 행을 클릭하면 우측에 상세 패널이 열립니다.
  </Step>
</Steps>

## [2] 품목 정보 수정하기

상세 패널에서 품목의 속성값을 편집하고 저장합니다.

<Frame>
  <img src="/images/item-management/03-edit.png" alt="품목 정보 수정 화면" />
</Frame>

<Steps>
  <Step title="수정할 품목 열기">
    목록에서 품목 행을 클릭해 상세 패널을 엽니다.
  </Step>
  <Step title="품목 정보 수정">
    품명, 출시일, 단종일, 카테고리, 담당자 등을 편집합니다. 품번과 등록일은 읽기 전용이라 수정할 수 없습니다.
    - 카테고리는 대분류를 바꾸면 중분류가, 중분류를 바꾸면 소분류가 그에 맞게 갱신됩니다.
    - 출시일 입력은 신제품 판정에 영향을 줍니다. 출시일로부터 신제품 판정 기준 개월이 지나지 않은 품목은 품명 옆에 '신제품' 태그가 표시되며, 기준 개월이 지나면 태그는 자동으로 사라집니다.
  </Step>
  <Step title="저장 / 취소">
    **[저장]** 을 클릭하면 '저장되었습니다.' 토스트가 표시되고 목록과 패널에 변경 내용이 반영됩니다. **[취소]** 를 클릭하면 변경 내용이 반영되지 않고 기존 값이 유지됩니다.
  </Step>
</Steps>

## [3] 사용자 속성 관리하기

품목에 담을 정보 항목을 직접 정의하고, 목록 표시 여부와 이름을 관리합니다.

<Frame>
  <img src="/images/item-management/04-user-attributes.png" alt="사용자 속성 관리 모달" />
</Frame>

<Steps>
  <Step title="속성 관리 모달 열기">
    액션 바 우측의 **[속성 관리]** 버튼을 클릭합니다. 이 모달은 별도 저장 버튼이 없으며 모든 변경이 즉시 반영됩니다.
  </Step>
  <Step title="사용자 속성 추가">
    **[사용자 속성 추가]** 를 클릭하고 속성 코드(영문 소문자·숫자·언더바만 허용)와 속성명을 입력한 뒤 **[추가]** 를 클릭합니다. 빈 코드, 중복 코드는 추가되지 않습니다.
  </Step>
  <Step title="속성명 변경">
    속성명을 클릭해 새 이름을 입력하고 Enter 키를 누르거나 필드 밖을 클릭합니다. 변경된 이름은 목록 표의 헤더명, 상세 패널의 필드 라벨, 속성 관리 목록에 함께 반영됩니다. (속성 코드는 변경되지 않습니다.)
  </Step>
  <Step title="목록 표시 켜고 끄기">
    각 속성의 '목록 표시' 토글을 켜면 품목관리 표에 해당 컬럼이 즉시 나타나고, 끄면 사라집니다. 필수 속성(품번, 품명)은 자물쇠 표시되어 있으며 항상 켜짐 상태입니다.
  </Step>
  <Step title="사용자 속성 삭제">
    속성 행의 삭제(✕)를 클릭하면 확인 모달이 표시됩니다. **[삭제]** 를 누르면 속성 정의와 모든 품목의 해당 값이 함께 제거되며, 되돌릴 수 없습니다.
  </Step>
</Steps>

## [4] 담당자 지정하기

품목별 담당자를 여러 명 지정하고 관리합니다.

<Frame>
  <img src="/images/item-management/05-assignee.png" alt="담당자 지정 화면" />
</Frame>

<Steps>
  <Step title="담당자 추가">
    상세 패널의 **[담당자 추가]** 버튼을 클릭하면 드롭다운이 열립니다. 사용자를 선택하면 '이름(로그인ID)' 형식의 칩으로 추가됩니다. (여러 명 지정 가능)
  </Step>
  <Step title="담당자 제거 후 저장">
    담당자 칩의 ✕를 클릭해 제거한 뒤 **[저장]** 을 클릭하면 반영됩니다.
  </Step>
</Steps>

## [5] 단종 처리하기

특정 시점부터 판매가 종료되는 품목을 단종으로 표시합니다. 단종은 활성 여부와 별개이며, 단종 처리해도 활성 상태는 유지됩니다.

<Frame>
  <img src="/images/item-management/06-discontinue.png" alt="단종 처리 화면" />
</Frame>

<Steps>
  <Step title="한 품목 단종 처리">
    상세 패널에서 단종일을 입력하고 **[저장]** 합니다. 단종일이 미래이면 목록의 단종 상태 컬럼에 **[예정]** 배지와 단종일이, 오늘 이하이면 **[단종]** 배지가 표시됩니다.
  </Step>
  <Step title="여러 품목 일괄 단종">
    목록에서 품목을 체크한 뒤 **[단종 설정]** 버튼을 클릭합니다. 모달에서 단종일을 입력하고 **[저장]** 하면 선택한 모든 품목에 동일한 단종일이 적용됩니다. (기존 단종일은 덮어씀)

    <Frame>
      <img src="/images/item-management/07-discontinue-bulk.png" alt="일괄 단종 설정 모달" />
    </Frame>
  </Step>
  <Step title="단종 해제">
    상세 패널에서 단종일 필드를 비우고 **[저장]** 하면 단종 상태 컬럼이 '—'로 돌아갑니다. 단종은 활성과 별개 축이므로 활성 여부는 그대로 유지됩니다.
  </Step>
</Steps>

<Warning>
  **단종일이 지나도 품목은 자동으로 비활성 처리되지 않습니다. 단종 상태이면서 활성인 품목은 수요예측에 계속 노출됩니다. 품목의 수요예측 메뉴 노출에 영향을 주는 것은 활성/비활성 상태입니다.**
</Warning>

## [6] 활성 여부(수요예측 포함/제외) 설정하기

품목 단위로 수요예측 화면 노출 여부를 제어합니다. 비활성은 화면 노출만 끄며, 출고 이력 합산에는 영향을 주지 않습니다.

<Frame>
  <img src="/images/item-management/08-active.png" alt="활성 여부 설정 화면" />
</Frame>

<Steps>
  <Step title="한 품목 즉시 전환">
    상세 패널 헤더의 활성/비활성 토글을 클릭하면 저장 없이 즉시 반영되고, 목록의 상태 컬럼이 갱신됩니다. 활동 이력에도 '활성 처리'/'비활성 처리'가 1건 기록됩니다.
  </Step>
  <Step title="여러 품목 일괄 설정">
    목록에서 품목을 체크한 뒤 **[활성 여부 설정]** 버튼을 클릭합니다. 모달에서 활성/비활성을 선택하고 **[저장]** 하면 선택 품목에 일괄 반영됩니다. 이미 같은 상태인 품목은 변경 없이 무시됩니다.

    <Frame>
      <img src="/images/item-management/09-active-bulk.png" alt="일괄 활성 여부 설정 모달" />
    </Frame>
  </Step>
</Steps>

<Warning>
  **예측 그룹에 속한 품목은 대표 지정에 따라 활성 여부가 자동으로 설정되므로(대표 품목은 활성, 구성 품목은 비활성), 해당 토글이 잠겨 있고 일괄 설정에서도 제외됩니다. 활성/비활성 설정은 그룹 미소속 품목에만 적용됩니다.**
</Warning>

## [7] 신제품 판정 기준 관리하기

출시일을 기준으로 신제품을 자동 판정합니다. 판정 기준 개월을 조정할 수 있습니다.

<Frame>
  <img src="/images/item-management/10-new-product.png" alt="신제품 판정 기준 설정" />
</Frame>

<Steps>
  <Step title="신제품 태그 확인">
    출시일이 신제품 기준 개월(기본 6개월) 이내인 품목은 목록에서 품명 옆에 '신제품' 태그가 자동으로 표시됩니다.
  </Step>
  <Step title="신제품 유지 기간 조절">
    상태 필터 옆 신제품 칩의 설정 아이콘을 클릭해 기준 개월을 입력하고 **[저장]** 합니다. 1\~60 범위만 허용되며, 벗어나면 '1\~60 사이 숫자 입력' 안내가 표시됩니다. 저장하면 목록이 즉시 재판정되어 신제품 태그가 갱신되며, 이 기준은 전체 품목에 일괄 적용됩니다.
  </Step>
</Steps>

## [8] 예측 그룹 만들고 관리하기

리뉴얼이나 업그레이드로 **유사·연관성이 높은 품목이 품명/코드가 바뀌어** 연이어 판매되는 경우가 있습니다. 이러한 유사 품목들을 하나의 예측 그룹으로 묶으면, **과거 판매 실적을 끊기지 않고 모델에 학습시킬 수 있으며, 딥플로우에서 하나의 데이터로 관리할 수 있습니다.**

예측 그룹 생성 또는 수정 시에 **대표 품목을 반드시 지정합니다.** 나머지 구성 품목의 과거 출고 실적은 대표 품목으로 합산되어 대표 품목 하나로 수요예측을 확인할 수 있습니다. 한 품목은 최대 1개 그룹에만 속하며, 대표 품목을 포함해 품목이 2개 이상일 때 그룹이 성립합니다.

<Frame>
  <img src="/images/item-management/11-forecast-group.png" alt="예측 그룹 관리 화면" />
</Frame>

<Steps>
  <Step title="새 그룹 만들기">
    묶을 품목 중 하나의 상세 패널을 엽니다. 예측 그룹 영역의 **[+ 품목 연결]** 을 클릭하면 '그룹에 품목 연결' 모달이 열립니다. 검색으로 함께 묶을 품목을 찾아 체크합니다. 아무 품목도 선택하지 않으면 **[연결]** 버튼은 비활성입니다.
  </Step>
  <Step title="대표 품목 지정">
    품목을 선택하면 하단에 '대표품목 선택' 섹션이 나타납니다. 후보(현재 품목 + 선택한 품목) 중에서 대표를 지정합니다. **[연결]** 을 클릭하면 그룹이 생성되고, 그룹에 속한 품목은 품목관리 화면의 '대표품번' 컬럼에 대표 품목의 품번이 함께 표시됩니다. 대표품번이 같은 품목들은 같은 예측 그룹에 속해 있음을 나타냅니다.
  </Step>
  <Step title="대표 품목과 활성 상태의 관계">
    그룹 내 수요예측 상태는 대표 품목은 활성, 구성 품목은 비활성으로 고정되며 개별 토글이 불가합니다. 구성 품목의 지난 기간 출고량은 대표 품목으로 합산되어 수요예측 화면에 노출됩니다.
  </Step>
  <Step title="대표 품목 변경">
    구성 품목 목록에서 원하는 구성 품목 행의 '대표 품목으로 지정' 링크를 클릭하면 '대표 품목 변경' 확인 모달이 열립니다. **[저장]** 하면 대표가 이동하며, 새 대표 품목은 활성, 나머지 구성 품목은 비활성이 됩니다.
  </Step>
  <Step title="다른 그룹과 병합">
    '그룹에 품목 연결' 모달에서 이미 다른 그룹에 속한 품목('그룹 소속' 배지)을 연결하면 그 그룹 전체가 통째로 병합됩니다. 단, 서로 다른 두 그룹의 품목을 동시에 선택하면 연결이 차단됩니다. (한 번에 병합 가능한 기존 그룹은 1개)
  </Step>
  <Step title="구성 품목 연결 해제">
    구성 품목 목록에서 해당 행의 🗑(제거)를 클릭하면 '품목 연결 해제' 모달이 열립니다. 해제 후 그 품목의 수요예측 상태(활성/비활성)를 선택하고 **[해제]** 합니다. 대표 품목은 제거 버튼이 비활성이므로, 먼저 다른 구성 품목을 대표로 바꾼 뒤 제거해야 합니다. 구성 품목이 모두 빠지고 대표 품목만 남으면 그룹이 자동으로 해체되고 단독(미소속) 품목이 됩니다.
  </Step>
</Steps>

## [9] 변경 이력 확인하기

품목 정보를 누가 언제 변경했는지 추적합니다.

<Frame>
  <img src="/images/item-management/12-history.png" alt="변경 이력 화면" />
</Frame>

<Steps>
  <Step title="활동 이력 보기">
    상세 패널의 활동 이력 영역에서 날짜·작성자·내용을 최신순으로 확인합니다. 속성값 수정, 단종 설정/해제, 활성/비활성 처리 등이 기록됩니다.
  </Step>
  <Step title="수정자 형식 구분">
    사용자가 변경한 이력은 사용자 이름으로, 데이터셋 업로드 등 시스템에 의한 변경은 '시스템'으로 표시됩니다.
  </Step>
</Steps>

## [10] 수요예측 화면과의 연동 이해하기

품목관리에서의 활성/비활성 상태 지정과 예측 그룹 설정은 수요예측 화면에 연동됩니다.

<Frame>
  <img src="/images/item-management/13-forecast-linkage.png" alt="수요예측 연동 화면" />
</Frame>

<Steps>
  <Step title="품목 노출 규칙">
    수요예측 화면에는 활성 품목만 노출됩니다. 비활성 품목은 예측값이 있어도 표시되지 않습니다. 단종 여부는 노출 조건이 아니므로, 단종이어도 활성이면 노출됩니다.
  </Step>
  <Step title="예측 그룹 노출">
    예측 그룹은 대표 품목 1개 행으로만 노출되며, 구성 품목의 출고량과 수요예측 값은 대표 품목으로 합산됩니다. 대표를 변경하면 노출 품목과 합산 대상이 즉시 새 대표로 이동합니다.
  </Step>
</Steps>
